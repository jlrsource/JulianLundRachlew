# Julian Lund Rachlew

Personlig nettside med CV, prosjekter og kontaktinfo – på norsk og engelsk.

**Live:** [LIM INN VERCEL-LENKE HER](https://)

## Innhold

- **Om meg** – kort introduksjon
- **Prosjekter** – web-apper du kan teste direkte:
  - [Innboforsikring-estimator](https://innboforsikring-estimat.vercel.app/)
  - [Algoritmevisualisering (AlgDat)](https://algoritmevisualisering-alg-dat.vercel.app/)
- **Erfaring og utdanning** – tidslinje
- **Kontakt**

## Funksjoner

- Språkbryter NO / EN
- Animert header som reagerer på scrolling
- Responsivt design for mobil og desktop

## Teknisk

Siden er én selvstendig `index.html` uten build-steg, hostet på [Vercel](https://vercel.com). Hver push til `main` deployes automatisk.

Kjør lokalt ved å åpne `index.html` i nettleseren.
